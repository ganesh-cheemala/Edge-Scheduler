# Edge Scheduler Lab (hosted package)

This is the minimal source package for deploying the software-only scheduling evaluation app. It runs with model-generated workload archetypes and does not bundle downloaded source archives, processed task tables, or prior experiment outputs.

See `DEPLOYMENT.md` for the Streamlit Community Cloud setup steps and interpretation notes. To start locally, install `requirements.txt` and run `python -m streamlit run app.py`.
